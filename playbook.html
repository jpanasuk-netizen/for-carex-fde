04 — The path · written so the next FDE can run it

Discover. Build. Measure. Leave.

Discover

Artifact: Environment Summary. Owner, date, unofficial definitions, what is on fire, what already works. Success metric written before anyone touches config. You posted that line. It is already the cover of my file.

Decompose

Artifact: Upgrade / build roadmap. Configure vs automate vs build vs simplify. I pick the smallest thing that moves the metric. Formal SWE is not required. Judgment is.

Build / configure

Workflows, agent skills, document schemas, integrations, lightweight apps. Agentic tools in daily work: OpenClaw, local Ollama pipeline, bounded MCP. Prototype on the customer’s data, not a sandbox story.

Prove go-live

Artifact: Six-class test — operability, same-data, security, performance, 3rd-party, HA/DR. QA twin of production. If it only works when I am in the chair, it is not deployed.

Measure after

Dawn 8h→1h. Mercedes +200%. West Bend −50%. Lab: 1.39→37.47 tok/s. Write the after next to the before. If the number did not move, we did not ship value. We shipped theater.

Leave the team

Artifact: Named skill-up. Cheat sheet. Playbook. Hypercare default. TCS kept Mercedes. Farmers named the skill-up in the review. Hire two starts here, not from my Slack.

When it burns. 20 troubled accounts, 19 recovered. Milwaukee insurer: three months dark, closed in two days. Founding FDE still does support. Monitoring, troubleshooting, reliability — that is the job after the demo.
